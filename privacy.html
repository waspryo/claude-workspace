プライバシーポリシー

claude-workspace ／ 最終更新日: 2026年10月12日

1. 本ツールの性質

claude-workspace は、作者本人が自分の業務環境を自動化するために作成した 個人利用のツールです。第三者に配布しておらず、作者本人以外のユーザーは存在しません。

2. 取得する情報

本ツールは、作者本人が許可した範囲で、本人の Google アカウントの以下の情報にアクセスします。

  • Gmail のメール（検索・閲覧・作成・送信）
  • Google カレンダーの予定（閲覧・作成・更新・削除）
  • Google ドライブ上のファイル、スプレッドシート、ドキュメント（閲覧・作成・編集）
  • アカウントのメールアドレスおよび基本的なプロフィール情報

3. 情報の利用目的

取得した情報は、作者本人の指示に基づく作業（メールの確認と返信、予定の登録、 資料の作成と整理など）を実行する目的のみに利用します。 それ以外の目的には一切利用しません。

4. 情報の保存場所

OAuth のアクセストークンおよびリフレッシュトークンは、 作者本人のパソコン内のローカルファイルにのみ保存されます。 外部のサーバーやデータベースには保存しません。 Google アカウントから取得したデータも、処理のためにメモリ上で扱うのみで、 本ツールが独自に蓄積・保管することはありません。

5. 第三者への提供

取得した情報を第三者へ販売、譲渡、貸与することは一切ありません。 広告配信、プロファイリング、機械学習モデルの学習には利用しません。 なお、処理の実行にあたっては Anthropic が提供する Claude を利用するため、 作業に必要な範囲の内容が Claude へ送信されます。

6. Google ユーザーデータの取り扱い

本ツールによる Google API から取得した情報の使用および他アプリへの移送は、 Google API Services User Data Policy（Limited Use の要件を含む）に従います。

7. アクセスの取り消し

付与したアクセス権は、 Google アカウントの「サードパーティ アプリとの連携」 からいつでも取り消せます。取り消すと、ローカルに保存されたトークンは無効になります。

8. 保存期間と削除

ローカルのトークンファイルは、不要になった時点で削除します。 アクセスを取り消した場合、またはツールの利用を終了した場合は、 該当するトークンファイルを削除します。

9. 本ポリシーの変更

本ポリシーは必要に応じて更新します。更新した場合は本ページの最終更新日を改めます。

10. お問い合わせ

本ツールおよび本ポリシーに関するお問い合わせは、 GitHub リポジトリの Issue からお願いします。
