claude-workspace

個人の業務環境を自動化するための、作者本人専用ツールです。

概要

Claude Code と Model Context Protocol（MCP）サーバーを組み合わせて、 メール・カレンダー・スプレッドシートの読み書きを自動化するローカル環境です。 作者本人のパソコン上でのみ動作し、第三者への配布や一般公開はしていません。

できること

  • Gmail のメール検索・取得・送信
  • Google カレンダーの予定の参照・登録・更新
  • Google ドライブ / スプレッドシート / ドキュメントの読み書き

Google アカウントへのアクセス

本ツールは Google OAuth 2.0 を使い、作者本人の Google アカウントにアクセスします。 アクセストークンは本人のパソコン内にのみ保存され、外部のサーバーへは送信されません。 取り扱いの詳細はプライバシーポリシーに記載しています。
